# FitLog

FitLog is a responsive workout library application built with Next.js. Users can browse workouts, view exercise details, add workouts to today's plan, save workouts for later, and track their workout progress.

## Technologies Used

- Next.js
- React
- Tailwind CSS
- DaisyUI
- React Toastify
- Lucide React
- Local Storage

## Key Features

1. Browse 12 workouts fetched from an API.
2. View detailed information for each workout.
3. Save workouts for later and manage them from the My Plan page.
4. Mark workouts as done or remove them with toast notifications.
5. Sort workouts in My Plan by Duration, Calories, or Rating.
6. Plan and Saved data persist using Local Storage.
7. Fully responsive design for mobile, tablet, and desktop.
